# 3D-ChessBot
A 3D chess tool that allows the user to play games against a simple AI opponent on a 3-dimensional chessboard represented by an NxNxN matrix

# Requirements and Dependencies
This program has no dependencies other than Python 3.14 or later

# Installation Instructions
This project is still in the early concept phase and therefore does not have executable code yet
When the code IS ready for execution, you can launch it by downloading the code from this repository,
opening it up in a command-line interface and running ./ChessBot.exe

# Usage Instructions
Run this program in a command-line interface of your choice, and any required user input will be requested on the command line.
